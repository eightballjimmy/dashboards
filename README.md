# dashboards

Static sports betting-model dashboards (NFL, NFL TD, NFL props, CFB, MLB, NHL, tennis).

Live site: https://eightballjimmy.github.io/dashboards/

Content is auto-published from a private box every ~10 minutes by `dashboards-bot`
and deployed via GitHub Actions (`.github/workflows/pages.yml`). Do not edit the
HTML here by hand; it is overwritten on each publish.
